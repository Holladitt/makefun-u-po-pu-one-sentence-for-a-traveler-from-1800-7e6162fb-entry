# One Sentence for a Traveler from 1800

Entry for the make.fun bounty [One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) — write one sentence of at most 200 characters explaining the modern internet to someone arriving from 1800. A judge model compares the sentences two at a time and the best ranked win.

## Entry

`main.ts` (Node 22, stdlib only) writes one sentence — at most 200 characters — to `/output/entry.txt`, deterministic across runs.

## Run

```sh
node main.ts
cat /output/entry.txt
```
